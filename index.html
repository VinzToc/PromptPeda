⚖️ RGPD – protection des données
Cette application fonctionne sans compte, sans serveur de données, sans cookie ni outil de suivi. Tout est traité dans votre navigateur ; les documents importés ne quittent pas votre appareil.
  • N'importez pas de document comportant des données personnelles d'élèves (noms, notes, appréciations) et n'en saisissez pas dans le prompt envoyé à Claude.
  • Les applications que vous créerez avec ce prompt doivent elles aussi respecter le RGPD : minimisation des données, information des élèves et des familles, consentement parental avant 15 ans, droit d'accès et de suppression, pas de transfert hors UE sans garanties.
  • Les fichiers exportés (.txt, .pdf, .xlsx) relèvent de votre responsabilité une fois enregistrés : stockez-les de façon sécurisée.
  • Hébergement des fichiers de l'application : GitHub Pages (l'hébergeur peut journaliser l'adresse IP, sans aucune donnée d'élève).
